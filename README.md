# UPAD Events

Interactive event pages for the Uttar Pradesh Association of Detroit (UPAD).

This repository hosts dedicated web pages for UPAD events. Each event is maintained independently with its own webpage and supporting assets.

## Event Structure

Events are organized by year and event name.

Example:

- `2026/diwali/`
- `2026/holi/`
- `2026/picnic/`
- `2026/kavi-sammelan/`

Each event folder may contain:

- `index.html` — Main event webpage
- `assets/` — Hero images, logos, QR codes and other event assets
